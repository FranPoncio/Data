El flujo en 5 fases

Leer → Modelar → Medir → Armar → Revisar. Cada fase tiene su prompt listo para usar.

1 · LEER

Entiende el negocio

Define preguntas y KPIs a partir de tu brief y tus datos.

2 · MODELAR

Esquema estrella

Hechos, dimensiones y relaciones bien armadas.

3 · MEDIR

DAX + Power Query

Medidas y transformaciones listas para pegar.

4 · ARMAR

Layout y narrativa

Qué visual, dónde, y el texto técnico del informe.

5 · REVISAR

Control de calidad

Totales, coherencia, seguridad y nombres.

Empezar en 5 pasos

  1. Instalá Power BI Desktop (gratis).
  2. Abrí el ejemplo Ventas Retail.
  3. Importá los CSV de datos/ (Obtener datos → Texto/CSV).
  4. Pegá las medidas de medidas.dax (Modelado → Nueva medida).
  5. Armá los visuales siguiendo el README del ejemplo.

ℹ️ Las imágenes de dashboards son maquetas de diseño que muestran el resultado esperado — no capturas de tu Power BI. Cuando lo armes con tus datos, el tuyo se va a ver así.
