# 🧪 Ejemplos

[⬅️ Volver al índice](../README.md)

Dos proyectos **completos y reproducibles**. Cada uno trae datos, medidas y un paso a paso. Elegí el que más se parezca a lo tuyo.

| Ejemplo | Para qué sirve | Nivel |
|---------|----------------|-------|
| 🛒 [**Ventas Retail**](ventas-retail/) | Dashboard comercial clásico: ventas, margen, ranking, mapa. El mejor para empezar. | 🟢 Principiante |
| 🏗️ [**Proyecto EVM**](proyecto-evm/) | Informe técnico de control de proyecto (Earned Value): CPI, SPI, curva S, proyección de costo. | 🟡 Intermedio |

## Cómo usarlos
1. Entrá al ejemplo y leé su `README.md`.
2. Importá los CSV de `datos/` en Power BI Desktop.
3. Pegá las medidas de `modelo/medidas.dax`.
4. Armá los visuales siguiendo la tabla del README y el mockup.

## Doble uso: practicar el agente
Cada ejemplo sirve también para **probar el [agente de IA](../agente-ia/)**: pegale la muestra de datos y corré las [5 fases](../agente-ia/flujo.md). Compará lo que propone la IA con el modelo/medidas que ya están en el ejemplo. Es la mejor forma de aprender a dirigir al agente.
